## 把账算完：月付、年付、续费、限购

买 VPS 最容易出错的一步在这里。同样是这台 1 核 1GB 的机器：

- 走常规云服务器月付 $4.00，一年 $48
- 走洛杉矶 Premium 年付，$49.99，一年只比月付贵 $2，但带宽从 100Mbps 不限流量换成 1Gbps / 1TB
- 走洛杉矶特价年付，$24.99，一年省一半，代价是带宽降到 20–30Mbps

也就是说，如果你已经确定要用满一年，月付几乎没有优势。反过来，第一次买、还没验证过这条线路在你所在城市的表现，多花 $8.8 走一个月付，比直接年付更稳。

续费这一块，双十一活动的页面上写明“续费同价不涨价”，并且默认季付、半年付、年付还有长周期折扣，优惠码可以与长周期折扣叠加。这条对整个成本判断影响很大：很多 VPS 的低价只存在于首期，第二年按原价续，实际两年总成本要翻倍。LightLayer 这次促销把续费价锁住了，但仅限活动页面列出的产品，不是全站政策，下单时以结算页显示的价格为准。

## 哪些人不用考虑 LightLayer

- 一定要三网全走 CN2 GIA、且不愿意自己验证线路质量：加钱买搬瓦工或 DMIT，省掉试错时间。
- 需要一个明确写死的退款窗口才敢下单：先确认条款，条款里找不到明确天数就按月付走。
- 流量消耗在 TB 级别（图床、中转、大文件分发）：1TB 月流量的款不够用，20–30Mbps 的特价机更不够，这类需求该看独立服务器或不限流量的国际线路款。
- 需要日本、韩国节点：LightLayer 的亚洲布局是香港、台湾、新加坡、马尼拉，没有日韩。

## 下单时会踩的几个点

优惠码在结账页的促销码栏填写，填完点应用再看总价变化，不要直接付款。活动页提到优惠码可以和季付、半年付、年付的长周期折扣叠加，叠加后的实际价格以结算页为准。

支付方式支持加密货币、信用卡、PayPal 和支付宝，其他方式需要联系客服。对国内用户来说支付宝这一项省掉了虚拟信用卡的麻烦。

线路是在下单时选定的，Global、Standard、Premium 是三套不同的年付价，结算页选的是哪条就是哪条。买完发现选错线路，通常只能按另一套价格重新下单，所以付款前把订单摘要里的线路名和带宽数字读一遍。

特价机限量供应（每款 50 台，独立服务器 20–30 台），下单后 1 小时内不付款订单会被取消。看到有货就先下单锁定，再慢慢配环境，比等想清楚了回来发现售罄要划算。
